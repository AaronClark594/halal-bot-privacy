Privacy Policy

How data is used for community onboarding and server moderation.

Last updated: October 28, 2026

About this policy

This policy describes data handled by Halal Bot when it is used in a Discord server. The bot supports member onboarding, application reviews, and server moderation.

Data the bot handles

  • Discord account and server details: user IDs, usernames, avatar links, account creation and server join dates, and server, channel, thread, and message identifiers.
  • Application information: submitted answers, including religious affiliation, gender, referral information, reasons for joining, and answers to server-configured questions.
  • Application conversations: message text, author names, and avatar links saved when an application review thread is archived.
  • Moderation records: infraction reasons and severity, related user and moderator IDs, and message text and attachment links included in moderator-requested snapshots.
  • Approval activity and configuration: moderator approval counts and dates, moderator usernames, and settings needed to operate the bot in the server.
  • Operational logs: diagnostic and error information, which may include Discord identifiers.

Why data is used

The operator uses these records for server moderation, including reviewing membership applications, managing onboarding roles, maintaining application review history, documenting infractions, and reviewing moderator approval activity.

Storage and access

The bot stores records in its database. Application reviews, moderation snapshots, and related logs may also appear in configured Discord channels and threads. Access to those messages depends on the server’s Discord permissions. Approval leaderboards show moderator approval activity to people permitted to use that feature.

Bot operators can access the database and operational logs in the environment where the bot is hosted. Server staff can access information shown in channels and threads they are permitted to view. Discord handles information sent through its platform under its Privacy Policy.

Retention

The operator currently keeps application and moderation records for server moderation and does not use a scheduled automatic deletion process. Leaving the server does not automatically erase stored records; the bot may mark an application inactive and remove its review messages or thread while retaining database records.

Privacy and deletion requests are handled manually through server support tickets, as described below.

Privacy questions and deletion requests

To ask about your information or request access, correction, or deletion, open a support ticket in the Discord server where you use Halal Bot. State that your ticket concerns Halal Bot privacy and describe your request.

Include your Discord user ID so staff can identify the relevant records. Staff may need to verify that the request concerns your account. Do not include passwords, bot tokens, or unrelated sensitive information.
